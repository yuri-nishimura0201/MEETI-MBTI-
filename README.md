# MEETI

**MBTI診断 × 自己紹介カードで、新しい出会いを楽しむ文化祭向けiOSアプリ。**

プロフィールと好きなことを登録して、自分だけのデジタル名刺を作れます。参加者同士の相性や共通点を確認し、名刺をQRコードから自分のスマートフォンで閲覧できます。

日本電子専門学校の文化祭に向けてチームで制作しました。このリポジトリは個人公開用で、[チームの共有リポジトリ](https://github.com/yuna-kono-jec/MEETI)の最新コードを反映しています。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| プロフィール登録 | ニックネーム・性別・年代・好きなこと・ひとことを入力 |
| 写真撮影 | プロフィール写真を撮影。登録は任意で、写真なしの場合はMBTIに対応するAssets画像を表示 |
| 簡易MBTI診断 | 12問・2択で診断。タイプを知っている場合は16タイプから直接選択 |
| デジタル名刺 | プロフィールとMBTIをまとめた自己紹介カードを作成 |
| 相性マッチング | 共有された参加者からBEST MATCHを探し、相性％・点数の内訳・共通の好きなことを表示 |
| 相手の条件指定 | 性別は「男性・女性・どちらでも」、年代は10歳ごとの区分などから選択 |
| QRコードで共有 | スマートフォンのブラウザで自分の名刺を閲覧 |
| 運営用の名刺管理 | 指定された運営アカウントで、登録済み名刺の一覧確認・1件ずつの削除 |

年代は0〜9歳、10〜19歳、20〜29歳…90〜99歳、100歳以上。マッチング時は年代を指定しないこともできます。

## アプリの流れ

1. スタート画面からプロフィールを入力する。
2. 必要に応じて写真を撮影する。
3. 12問の診断、または直接選択でMBTIを決める。
4. 「名刺を作る」で参加者情報を保存し、自分の名刺を表示する。
5. 「マッチングへ進む」から相手の条件を選び、BEST MATCHと共通点を確認する。
6. 自分の名刺のQRコードをスマートフォンで読み取り、Web名刺を閲覧する。

名刺画面から直接QRコードを表示することもできます。

## MBTI診断・相性計算

診断はE/I・S/N・T/F・J/Pの各軸3問ずつ、合計12問。回答した側に1点を加算し、多かった指標を並べて4文字のMBTIを決めます。

相性は、次の配点による100点満点です。

| 項目 | 配点 |
| --- | ---: |
| E/Iが一致 | 18点 |
| S/Nが一致 | 18点 |
| T/Fが一致 | 17点 |
| J/Pが一致 | 17点 |
| 好きなことの一致 | 1個につき10点、最大30点 |

好きなことは、次の14項目から3つ選びます。

音楽・旅行・カフェ・映画・アニメ・スポーツ・読書・ゲーム・ショッピング・アウトドア・グルメ・犬・猫・アート

BEST MATCHでは自分自身を候補から外し、最高得点の相手を選びます。同率1位は全員表示し、条件に合う相手がいない場合は案内を表示します。

診断と相性スコアは、文化祭で会話のきっかけを作るためのアプリ独自の簡易的なものです。

## データの保存と複数端末での共有

複数のiPhoneで登録した参加者同士をマッチングできるよう、Supabaseを共通の保存先として利用しています。

| 保存先・仕組み | 役割 |
| --- | --- |
| Supabase Databaseの`participants` | 参加者番号、ニックネーム、MBTI、好きなこと、一言、性別、年代、写真の保存場所などを保存 |
| Supabase Storageの`meeti-photos` | プロフィール写真を保存 |
| Supabase Auth | 端末の認証。未ログインの場合は匿名ログインする処理を用意 |
| SwiftData | Supabaseへの保存に成功した参加者情報を、その端末内にも保存 |

マッチング時はSupabaseから参加者情報を取得し、Swiftのコードで相性を計算します。参加者の保存・取得には通信が必要です。

## 写真とWeb名刺

撮影前に、写真がWeb名刺に使われ、QRコードを知っている人が閲覧できることを案内します。写真は名刺やマッチング結果にも表示します。

写真を登録しない場合は、MBTIに対応するAssets画像を使います。

## 運営用の名刺管理

スタート画面の「運営用ログイン」からログインし、「登録済み名刺を確認・削除」を開きます。指定された運営アカウントでのみ管理画面のデータを読み込みます。

一覧のごみ箱ボタンを押すと確認画面が出て、削除を確定すると`meeti-delete-participant`を呼び出します。参加者情報・写真・Web写真共有情報の削除をサーバーへ依頼し、成功後は操作中の端末のSwiftDataからも同じ参加者を削除します。

削除機能には、サーバー側の運営権限チェックとEdge Functionの設定が必要です。他の端末に保存されたローカルデータや、すでに共有したURL内のプロフィール情報まで一括で消す仕組みではありません。

## 動作を軽くするための工夫

- 撮影した写真のJPEG変換やアップロード前の画像処理をバックグラウンドで行う。
- 表示用の写真を最大1024pxに縮小し、入力や画面更新のたびに元写真を処理し直さない。
- 縮小画像や取得済み写真を、上限付きのキャッシュで再利用する。
- マッチングでは先に参加者情報だけを取得し、写真は表示が必要になってから取得する。
- 同率の相手が多い場合も、見えるカードから表示する。
- QRコードはURLが決まったときに生成し、完成した画像を再利用する。

確認内容と実機での確認手順は[軽量化の記録](docs/PERFORMANCE-20261023.md)にまとめています。

## 使用技術

- Swift / SwiftUI：画面とアプリの処理
- SwiftData：端末内のデータ保存
- Supabase：認証・参加者情報の共有・写真保存・Edge Functions
- UIKit / ImageIO：カメラ撮影・写真の変換と縮小
- Core Image：QRコード生成
- HTML / CSS / JavaScript：ブラウザで表示するWeb名刺
- XCTest：診断・相性計算・画像処理のテスト

## 起動方法

1. このリポジトリをダウンロードまたはCloneする。
2. `MEETI.xcodeproj`をXcodeで開く。
3. Swift Packageの依存関係が読み込まれるまで待つ。
4. 実行するiPhoneシミュレータ、または実機を選んでRunする。

ビルド確認環境はXcode 26.3、シミュレータの操作確認環境はiOS 26.3です。カメラ撮影にはiPhone・iPadの実機が必要で、シミュレータでは写真なしで画面を確認できます。

参加者登録・共有・写真付きWeb名刺・管理機能を使う場合は、Supabase側の設定も必要です。

- `SupabaseService.swift`：接続先URLと公開用APIキーを設定。
- Database・Storage・認証・アクセス権限：[Supabaseの準備](supabase/README.md)を参照。
- Edge Functions：`meeti-register-photo`、`meeti-photo-url`、`meeti-delete-participant`を別途用意。
- Web名刺：公開先と`CardURLBuilder.swift`、`MEETI/WebCard/script.js`の接続先を合わせる。

既存環境へ接続する場合は、チームの管理者に確認してください。管理者用の秘密キーやパスワードはアプリに入れません。Edge Functionsのサーバー側ソースは、このリポジトリには含まれていません。

## テスト

MacでXcodeの開発環境を選択した状態で、リポジトリのルートから実行します。

```sh
swift test
```

診断、16タイプ、好きなことの選択、相性計算、自分除外、同率1位、候補0人、性別・年代条件、SwiftDataからの取得、写真の縮小・向き・再利用・キャンセルを確認する16件のテストがあります。

カメラ撮影やSupabaseへの登録・削除・複数端末での共有は、単体テストとは別に確認します。

## 主な担当部分・AIの活用

主な担当は、簡易MBTI診断、相性計算、BEST MATCHの判定、画面やアップアイコンのデザイン、軽量改善です。画面やデータ連携はチームで分担して制作しています。

開発ではAIを、Swiftの構文やSupabaseの使い方の確認、コード作成の補助、エラーや動作の重さの調査に使いました。生成されたコードの意味を確認し、テストや画面の動作確認をしながら進めています。
