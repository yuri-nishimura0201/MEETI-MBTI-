# MEETI
### MBTI診断 × 自己紹介カード

文化祭の来場者が、簡易MBTI診断と自己紹介から
自分だけのデジタル自己紹介カードを作成できるiOSアプリです。

その日の参加者データをもとに、MBTIや好きなことから
相性の良い人「BEST MATCH」を見つけることができます。

作成したカードはQRコードを使って、
自分のスマートフォンから見ることができます。

---

## 📱 主な機能

- 自己紹介プロフィールの入力
- 簡易MBTI診断
- MBTIを知っている場合の16タイプ直接選択
- デジタル自己紹介カードの作成
- SwiftDataを使用した参加者データの保存
- MBTI・好きなことをもとにした相性計算
- その日の参加者から「BEST MATCH」を表示
- 相手の自己紹介カードを表示
- QRコードからWeb版自己紹介カードを表示

## 💡 相性計算の仕組み

相性度を100点満点で計算します。

- MBTIの一致度：最大70点
- 好きなことの共通点：最大30点

MBTIは4つの指標を比較し、
好きなことは共通する項目数に応じて点数を加算しています。
